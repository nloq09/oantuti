Hướng dẫn viết bot
Bot nhận từng dòng JSON từ stdin và trả một dòng ACTION JSON qua stdout, đúng sequence và nước đi trong legalActions. Flush sau mỗi phản hồi; dùng stderr để debug. Java dùng class Main, không package.
{"type":"ACTION","sequence":42,"action":{"type":"PASS"}}
Chọn một hành động hợp lệ từ legalActions; PASS chỉ dùng khi luật cho phép. Tab để thụt dòng, Ctrl/Cmd+S để lưu nháp, Ctrl/Cmd+Z để hoàn tác.
